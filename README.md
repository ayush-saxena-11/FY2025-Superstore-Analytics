# FY2025 Superstore Business Performance Analysis

> End-to-end data analytics project | Excel · Python · Power BI

## Key Findings
- 📉 Tables sub-category loses **$17,753** annually
- ⚠️ Discounts above 20% cause **average losses** per order  
- 🔍 Furniture earns only **2.6% margin** vs Technology's **17.4%**
- 🌍 West region outperforms South by **$334K** in revenue

## KPIs
| Metric | Value |

| Net Profit | $292,297 |
| Profit Margin | 12.22% |

## Recommendations
1. Cap all discounts at 20% → recover $80K–$100K profit
2. Reprice Tables sub-category → recover $17K annually
3. Shift marketing to Technology (17.4% margin)
4. Expand South region strategy
5. Grow Corporate segment with B2B pricing tiers
